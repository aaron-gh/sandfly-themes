# SandFly sound themes

Sound themes for [SandFly](https://github.com/aaron-gh/SandFly).

## Themes

* **SandFly 0.2.1** (`sandfly-0.2.1.zip`): the sounds of SandFly 0.2.1, before SandFly 0.3.0 replaced them. As in 0.2.1, control sounds, screen on, row wraps, cursor moves and reading control changes have no sound. The braille display connection sounds and the braille keyboard typing sounds are SandFly's current ones.

## Installing a theme

In SandFly, go to Settings > Sound and vibration > Sound themes, choose From a link under Install a theme, and enter:

    https://github.com/aaron-gh/sandfly-themes/raw/master/sandfly-0.2.1.zip

You can also add this repository under From a source to list its themes:

    https://github.com/aaron-gh/sandfly-themes

To go back to the current sounds, choose the SandFly theme in Sound themes.
